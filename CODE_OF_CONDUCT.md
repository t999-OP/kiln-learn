# Code of Conduct

Kiln is a project about teaching and learning, so we expect everyone in its spaces — issues, pull requests, discussions, and courses published on community instances — to act like good teachers and good classmates.

**Be kind and patient.** People join with every level of experience. Explain, don't belittle.

**Be respectful.** No harassment, discrimination, personal attacks, or sexualized content. Disagree with ideas, not people.

**Be honest.** Credit others' work, respect licenses, and don't present generated content as something it isn't.

**Assume good intent**, and accept feedback gracefully.

## Enforcement

Maintainers may edit or remove comments, commits, issues and other contributions that don't follow this code, and may temporarily or permanently ban contributors who repeatedly or seriously violate it. Report problems privately to the maintainers through GitHub (for example via a [private security advisory](https://github.com/t999-OP/kiln-learn/security/advisories/new) if the matter is sensitive). Reports are handled confidentially.
